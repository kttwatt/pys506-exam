## 1. เต้านม (Breast)

### 1.1 การซักประวัติและแนวทางตรวจคัดกรอง [สไลด์ Breast] [หน้า 4-18]

| ประเด็น | รายละเอียด | เทคนิค/ท่าทาง | ค่าปกติ/สิ่งที่ต้องบันทึก | อ้างอิง |
|---|---|---|---|---|
| BSE (Breast Self Exam) อายุ 20-39 ปี | ตรวจโดยแพทย์/บุคลากรอย่างน้อยทุก 3 ปี + ตรวจเต้านมด้วยตนเองทุกเดือน | - | - | [หน้า 7-10] |
| BSE อายุ 40 ปีขึ้นไป | Mammogram ทุกปี + ตรวจโดยบุคลากรทุกปี + ตรวจด้วยตนเองทุกเดือน | - | - | [หน้า 11-14] |
| Clinical Breast Exam ประกอบด้วย | History, Visual Inspection, Palpation (ทั้งสองเต้านม รักแร้ โคนคอ) | - | - | [หน้า 15-18] |
| ปัจจัยเสี่ยง (Risk factors) | ประวัติครอบครัว, ได้รับ estrogen นาน (มีประจำเดือนเร็ว/หมดประจำเดือนช้า), ยาคุมกำเนิด/ฮอร์โมนทดแทน, ดื่มแอลกอฮอล์, น้ำหนักเกิน/อ้วน | - | - | [หน้า 23-28] |

### 1.2 ขั้นตอนการตรวจ: Inspection ★★★ [สไลด์ Breast] [หน้า 29-59]

| ประเด็น | รายละเอียด | เทคนิค/ท่าทาง | ค่าปกติ/สิ่งที่ต้องบันทึก | อ้างอิง |
|---|---|---|---|---|
| ท่าทางที่ต้องตรวจ 3 ท่า | 1) แขนแนบลำตัว (arms at side) 2) มือเท้าสะเอว (hands on hips) 3) ยกแขนเหนือศีรษะ (arms above the head) | ดูการเปลี่ยนแปลงขนาด รูปร่าง ความสมมาตร พื้นผิว | - | [หน้า 33-38] |
| เต้านม: สิ่งที่ต้องดู | Size, Symmetry, Contour, Color, Lesion/mass, Skin/dimpling/retraction | - | ตัวอย่างบันทึก: "เต้านมมีขนาด...รูปร่าง...สมมาตรกัน ไม่มีก้อน ผิวหนังไม่มีรอยบุ๋ม ไม่มีการดึงรั้ง ผิวหนังสี... เส้นเลือดใต้ผิวหนังไม่โป่งพอง ไม่มีแผล ไม่มีผื่น" | [หน้า 39-52] |
| หัวนม: สิ่งที่ต้องดู | Color, Size, Shape, Direction, Lesion, Discharge | - | ตัวอย่างบันทึก: "หัวนมมีสี...สมมาตรกัน มีขนาดปกติ รูปร่าง...ไม่มีการดึงรั้งของหัวนม ไม่มีแผล ผื่น ไม่มีสิ่งขับหลั่ง" | [หน้า 53-59] |

### 1.3 ขั้นตอนการตรวจ: Palpation ★★★ [สไลด์ Breast] [หน้า 60-94]

| ประเด็น | รายละเอียด | เทคนิค/ท่าทาง | ค่าปกติ/สิ่งที่ต้องบันทึก | อ้างอิง |
|---|---|---|---|---|
| ท่าผู้ป่วย | Supine, งอแขนทำมุม 90 องศา | - | - | [หน้า 61-63] |
| ตำแหน่งที่คลำ | Supraclavicular, Axillary nodes, Nipples | - | - | [หน้า 64-67] |
| เต้านม: สิ่งที่คลำ | Consistency (ความนุ่ม), Elasticity (ความยืดหยุ่น), Mass | - | - | [หน้า 68-74] |
| หัวนม: สิ่งที่คลำ | Elasticity, Discharge | - | ตัวอย่างบันทึก: "ไม่พบก้อน หัวนมและเต้านมมีความยืดหยุ่นดี กดไม่เจ็บ ไม่มีสิ่งขับหลั่งใดๆ" | [หน้า 68-77] |
| หากพบก้อน ต้องบอก | ตำแหน่ง ขนาด รูปร่าง การเคลื่อนไหว การกดเจ็บ สีผิวหนังบริเวณที่มีก้อน | - | - | [หน้า 78-79] |
| หลัก "3 นิ้ว 3 ระดับ 3 แบบ" ★★★ | เทคนิคการคลำเต้านมมาตรฐาน (ระบุชื่อหลักไว้ แต่รายละเอียดแต่ละคำไม่ได้ขยายความในสไลด์) | - | - | [หน้า 80-83] |

### 1.4 ตำแหน่ง Quadrant และกลุ่มต่อมน้ำเหลืองที่รักแร้ ★★ [สไลด์ Breast] [หน้า 84-94]

| กลุ่มต่อมน้ำเหลือง | ตำแหน่ง | สิ่งที่ต้องดู/คลำ | ค่าปกติ | อ้างอิง |
|---|---|---|---|---|
| 1. Central group | ติดกับลำตัวด้านข้าง | ดู: ไม่มีการอักเสบ บวม แดง อุณหภูมิไม่ร้อน / คลำ: ไม่พบต่อมน้ำเหลือง กดไม่เจ็บ | ไม่พบต่อมน้ำเหลือง | [หน้า 84, 89-94] |
| 2. Lateral group | รักแร้ติดกับแขน | เช่นเดียวกัน | เช่นเดียวกัน | [หน้า 85] |
| 3. Anterior group | รักแร้ด้านหน้า | เช่นเดียวกัน | เช่นเดียวกัน | [หน้า 86] |
| 4. Posterior group | รักแร้ด้านหลัง | เช่นเดียวกัน | เช่นเดียวกัน | [หน้า 87] |

### 1.5 Benign Breast Masses และ Staging (ความรู้ประกอบ) [สไลด์ Breast] [หน้า 95-123]

| หัวข้อ | รายละเอียด | อ้างอิง |
|---|---|---|
| Benign Breast Masses | Breast cysts, Fibrocystic breast changes, Fibroadenoma, Ductal papilloma | [หน้า 95-99] |
| Stage 0 | ไม่ลุกลามในหรือนอกเต้านม (DCIS, LCIS / breast cancer in situ / noninvasive cancer) | [หน้า 101-103] |
| Stage I | ก้อนไม่เกิน ~1 นิ้ว ไม่ลามนอกเต้านม | [หน้า 104-105] |
| Stage II | ไม่เกิน 1 นิ้วแต่ลามต่อมน้ำเหลืองใต้แขน / 1-2 นิ้ว อาจลามหรือไม่ลาม / เกิน 2 นิ้วแต่ยังไม่ลามต่อมน้ำเหลือง | [หน้า 106-110] |
| Stage IIIA | เล็กกว่า 2 นิ้วแต่ลามต่อมน้ำเหลืองใต้แขน / ใหญ่กว่า 2 นิ้วและลามต่อมน้ำเหลืองใต้แขน | [หน้า 113-115] |
| Stage IIIB | ลามเนื้อเยื่อใกล้เต้านม (ผิวหนัง ผนังทรวงอก ซี่โครง กล้ามเนื้อ) หรือลามต่อมน้ำเหลืองในทรวงอกตามแนวกระดูกสันอก | [หน้า 116-119] |
| Stage IV | ลามไปอวัยวะอื่น (กระดูก ปอด ตับ สมอง) หรือลามผิวหนัง/ต่อมน้ำเหลืองบริเวณคอใกล้กระดูกไหปลาร้า | [หน้า 120-123] |

## 2. ช่องท้อง (Abdomen)

### 2.1 การซักประวัติ [สไลด์ Abdomen] [หน้า 16-34]

| ระบบ | อาการที่ต้องซัก | อ้างอิง |
|---|---|---|
| ทางเดินอาหาร | เบื่ออาหาร, คลื่นไส้, อาเจียนเป็นเลือด, ปวดท้อง, การเปลี่ยนแปลงของ bowel sounds, ท้องผูก, ท้องเสีย, ตัวเหลือง, กลั้นอุจจาระไม่ได้ | [หน้า 19-28] |
| ทางเดินปัสสาวะ | ปวดท้องเหนือหัวเหน่า, ถ่ายปัสสาวะลำบาก, กลั้นปัสสาวะไม่ได้, ถ่ายปัสสาวะเป็นเลือด, ปวดบริเวณไตหรือบั้นเอว | [หน้า 29-34] |
| Quadrants | RUQ, LUQ, RLQ, LLQ (ต้องตรวจให้ครบ 4 quadrants) | [หน้า 7-15] |

### 2.2 COLDSPA ★★★ [สไลด์ Abdomen] [หน้า 35-42]

| ตัวอักษร | ความหมาย | คำถาม/สิ่งที่ประเมิน | อ้างอิง |
|---|---|---|---|
| C | Character | ปวดอย่างไร เช่น จิด บิด | [หน้า 36] |
| O | Onset | เริ่มปวดเมื่อใด | [หน้า 37] |
| L | Location | บริเวณที่ปวด ลึก/ตื้น/เฉพาะที่/ปวดทั่วๆ | [หน้า 38] |
| D | Duration | ปวดนาน/บ่อยแค่ไหน/ปวดเวลาใดเป็นพิเศษ | [หน้า 39] |
| S | Severity | ปวดมากน้อยเพียงใด | [หน้า 40] |
| P | Pattern | อะไรทำให้อาการปวดเกิดขึ้น/หายไป | [หน้า 41] |
| A | Associated factors | อาการร่วม เช่น คลื่นไส้ ปวดศีรษะ ไข้ | [หน้า 42] |

### 2.3 ชนิดของ Abdominal Pain ★★ [สไลด์ Abdomen] [หน้า 43-49]

| ชนิด | ลักษณะ | อ้างอิง |
|---|---|---|
| 1. Visceral pain | บอกขอบเขตไม่แน่ชัด ปวดแบบ intermittent เป็นๆหายๆ | [หน้า 44-45] |
| 2. Parietal pain | ปวดตื้อๆ ความมาก/น้อยขึ้นกับชนิด/ปริมาณสิ่งที่สัมผัส peritoneum จะปวดมากขึ้นเมื่อคลำหน้าท้อง เคลื่อนไหว ไอ จาม | [หน้า 46-47] |
| 3. Referred pain | ปวดในบริเวณห่างไกลจากจุดกำเนิด เช่น ปวดไหล่ขวาอาจมาจาก Gallbladder/Liver มีปัญหา | [หน้า 48-49] |

### 2.4 การเตรียมตรวจร่างกายช่องท้อง [สไลด์ Abdomen] [หน้า 50-57]

1. นอนราบ หนุนหมอนผ่อนคลาย
2. ถ่ายปัสสาวะก่อนตรวจ
3. เปิดบริเวณหน้าท้องให้เห็นครบทั้ง 4 Q (ตั้งแต่ใต้ทรวงอกถึง anterior iliac spines ทั้งสองข้าง)
4. ต้องตรวจให้ครบทั้ง 4 Q
5. ผู้ตรวจยืนทางขวามือของผู้ป่วย
6. ใช้ 4 ทักษะในการตรวจ
7. ใช้ Stethoscope
[หน้า 51-57, 73-85]

### 2.5 ลำดับขั้นการตรวจ 4 ขั้นตอน ★★★ [สไลด์ Abdomen] [หน้า 58-170]

> **ลำดับสำคัญที่มักออกสอบ:** Inspection → **Auscultation** → Percussion → Palpation (ลำดับนี้สลับกับระบบอื่นที่ปกติ Percussion/Palpation มาก่อน เพราะการคลำ/เคาะจะไปกระตุ้นให้ bowel sounds เปลี่ยนแปลงก่อนฟังจริง) [หน้า 58-62, 105-106]

| ขั้นตอน | สิ่งที่ตรวจ/ประเมิน | เทคนิค | ค่าปกติ/เกณฑ์ | อ้างอิง |
|---|---|---|---|---|
| 1. Inspection | Skin color, Contour, Symmetry, Umbilicus, Peristalsis, Superficial mass, Pulsation | เปิดหน้าท้องให้เห็นตั้งแต่ใต้ทรวงอกถึง anterior iliac spines ทั้งสองข้าง | ตัวอย่างบันทึก: "หน้าท้องแบนราบ สีผิว... สะดือไม่โป่งนูนผิดปกติ ท้อง 2 ข้างสมมาตรกัน ไม่มีก้อน มองไม่เห็นการเคลื่อนไหวของลำไส้ ไม่พบการเต้นของชีพจรหลอดเลือดบริเวณหน้าท้อง ไม่พบการโป่งของหลอดเลือด" | [หน้า 63-85] |
| 2. Auscultation ★★★ | Bowel sound (ความถี่, ลักษณะ peristalsis), Pulsation | ฟังให้ครบ 4 Q, ใช้ diaphragm (ผู้ตรวจส่วนใหญ่ใช้), ฟังอย่างน้อย 10-15 วินาที; **ถ้าไม่ได้ยินเสียงเลยต้องฟังนาน 2 นาทีเต็ม** ก่อนสรุปว่าไม่มี bowel sound | ความถี่ปกติ 5-35 ครั้ง/นาที (bowel sound เกิดทุก 2-12 วินาที) | [หน้า 86-104] |
| 3. Percussion | ลมในช่องท้อง, ลักษณะก้อน, ขนาดตับ, ม้าม/ไต | เคาะเบาๆ ให้ครบ 4 Q | ปกติ: เสียงโปร่ง (tympanic) เพราะลมในลำไส้ลอยขึ้นผิวเมื่อผู้ป่วยนอนหงาย | [หน้า 107-119] |
| 4. Palpation | ถามผู้ป่วยก่อนว่าเจ็บ/ปวดบริเวณไหน; ถ้ามีอาการปวดท้อง **ให้คลำตำแหน่งที่ปวดเป็นลำดับสุดท้าย** | Light palpation (กดลึก ~1 ซม., ดูสีหน้าผู้ป่วยขณะคลำ) vs Deep/Bimanual palpation | ตัวอย่างบันทึก: "คลำไม่พบก้อน ไม่พบขอบเขตของตับและม้าม ตับไม่โตหรือคลำไม่พบตับและม้าม" | [หน้า 120-140] |

### 2.6 เทคนิคคลำ Light vs Deep (Bimanual) ★★ [สไลด์ Abdomen] [หน้า 128-132]

| เทคนิค | ใช้ตรวจหา |
|---|---|
| Light Palpation | แรงต้านของกล้ามเนื้อหน้าท้อง, ก้อนที่อยู่ตื้นๆ, บริเวณกดเจ็บ |
| Deep Palpation (Bimanual) | ก้อนบริเวณลึกในช่องท้อง, ตับ, ม้าม |
[หน้า 128-132]

### 2.7 เทคนิคคลำตับ (Liver Palpation) ★★★ [สไลด์ Abdomen] [หน้า 141-155]

- ผู้ตรวจยืนด้านขวาของผู้ป่วย
- วางมือซ้ายด้านหลังลำตัวผู้ป่วยด้านขวา ใต้บริเวณซี่โครงที่ 11 และ 12 กดดันขึ้น
- วางมือขวาบนหน้าท้องต่ำกว่าตำแหน่งขอบตับที่เคาะได้
- (ฉบับภาษาไทย) มือซ้ายสอดใต้ชายโครงซ้าย คลำบริเวณหน้าท้องจากสะดือทแยงมุม 45 องศาไปยังชายโครง

### 2.8 เทคนิคคลำม้าม (Spleen Palpation) ★★★ [สไลด์ Abdomen] [หน้า 156-170]

- ท่าทางถูกต้อง: จัดตำแหน่งผู้ป่วย ให้หายใจ คลำขณะหายใจเข้าลึกที่สุด (deepest full inspiration)
- มือข้างหนึ่งสอดใต้ด้านซ้ายผู้ป่วย อีกมือคลำ
- **หากคลำไม่ได้ ให้จัดท่า right lateral decubitus** แล้วคลำใหม่

## ★ จุดที่มักออกสอบ / จุดที่พลาดบ่อย

| หัวข้อ | ประเด็นที่ออกสอบบ่อย | ทำไมพลาดบ่อย | คำตอบที่ถูกต้อง (ตามสไลด์) | ระดับ |
|---|---|---|---|---|
| ลำดับการตรวจช่องท้อง | นักศึกษามักเรียงลำดับตามระบบอื่น (Inspection→Palpation→Percussion→Auscultation) | ระบบอื่น (เช่น หัวใจ ปอด) มักคลำ/เคาะก่อนฟัง แต่ท้องต่างออกไป | Inspection → **Auscultation** → Percussion → Palpation (ฟังก่อนคลำ/เคาะ เพื่อไม่ให้ bowel sound เปลี่ยนจากการกระตุ้น) | ★★★ |
| ความถี่ Bowel sound ปกติ | มักจำตัวเลขผิดหรือสลับกับ full listening time | มีตัวเลข 2 ชุด (ความถี่ปกติ vs ระยะเวลาฟังเมื่อไม่ได้ยินเสียง) ทำให้สับสน | ปกติ 5-35 ครั้ง/นาที; ถ้าฟัง 10-15 วินาทีไม่ได้ยิน ต้องฟังต่อให้ครบ **2 นาทีเต็ม** ก่อนสรุปว่าไม่มีเสียง | ★★★ |
| ลำดับการคลำเมื่อผู้ป่วยปวดท้อง | มักคลำจุดที่ปวดก่อนเป็นอันดับแรกตามสัญชาตญาณ | ผิดหลักการตรวจ เพราะการคลำจุดปวดก่อนจะทำให้ผู้ป่วยเกร็งและบิดเบือนผลตรวจจุดอื่น | ต้องถามตำแหน่งที่ปวดก่อน แล้ว **คลำตำแหน่งที่ปวดเป็นลำดับสุดท้าย** | ★★★ |
| COLDSPA ตัวย่อ | สับสนระหว่าง L (Location) กับ D (Duration) หรือสลับ P/A | ตัวย่อคล้ายกับ OPQRST ที่บางคนคุ้นเคยมากกว่า | C-Character, O-Onset, L-Location, D-Duration, S-Severity, P-Pattern, A-Associated factors | ★★★ |
| Abdominal pain 3 ชนิด | สับสน Visceral vs Parietal vs Referred pain | ทั้งสามมีลักษณะ "ปวดท้อง" คล้ายกันแต่กลไกต่างกัน | Visceral = ขอบเขตไม่ชัด เป็นๆหายๆ; Parietal = ปวดตื้อๆ แย่ลงเมื่อคลำ/ไอ/จาม (ระคายเคือง peritoneum); Referred = ปวดตำแหน่งอื่นที่ไม่ใช่จุดกำเนิด (เช่น ไหล่ขวา จาก gallbladder/liver) | ★★ |
| เทคนิคคลำม้าม | ลืมขั้นตอนสำรองเมื่อคลำม้ามไม่ได้ | ม้ามปกติมักคลำไม่ได้ นักศึกษาหยุดตรวจแทนที่จะเปลี่ยนท่า | หากคลำไม่ได้ (ไม่ผิดปกติ) ให้จัดท่า **right lateral decubitus** แล้วคลำซ้ำ | ★★★ |
| Light vs Deep palpation | สับสนว่าใช้เทคนิคไหนตรวจอะไร | ทั้งสองใช้มือคลำหน้าท้องเหมือนกัน ต่างที่ความลึก/วัตถุประสงค์ | Light = แรงต้านกล้ามเนื้อ, ก้อนตื้น, จุดกดเจ็บ; Deep(Bimanual) = ก้อนลึก, ตับ, ม้าม | ★★ |
| การตรวจเต้านม 3-3-3 | จำหลักไม่ครบ (3 นิ้ว 3 ระดับ 3 แบบ) | สไลด์ระบุชื่อหลักแต่ไม่ได้ขยายรายละเอียดแต่ละคำ นักศึกษามักเดาเติมเอง | สไลด์ระบุเพียงชื่อหลัก "3 นิ้ว 3 ระดับ 3 แบบ" ไม่มีรายละเอียดเพิ่มในเอกสารนี้ ต้องตรวจสอบจากแหล่งอื่นหากสอบถามรายละเอียด | ★★ |
| กลุ่มต่อมน้ำเหลืองรักแร้ | สับสนตำแหน่ง Central/Lateral/Anterior/Posterior | ชื่อคล้ายกันและตำแหน่งทางกายวิภาคซับซ้อน | Central = ติดลำตัวด้านข้าง, Lateral = ติดแขน, Anterior = รักแร้ด้านหน้า, Posterior = รักแร้ด้านหลัง | ★★ |
| ตำแหน่งมือคลำตับ | สับสนว่ามือซ้าย/ขวาอยู่ตำแหน่งไหน | มีทั้งเวอร์ชันภาษาอังกฤษ (ยืนขวา, มือซ้ายหลังลำตัวผู้ป่วยขวา) และเวอร์ชันไทยในสไลด์ (มือซ้ายสอดใต้ชายโครงซ้าย ทแยงมุม 45 องศา) ซึ่งอธิบายคนละมุมกัน | ต้องอ่านทั้งสองเวอร์ชันตามที่ปรากฏในสไลด์ (ดูหัวข้อ 2.7) เพราะสไลด์นำเสนอไว้ทั้งสองแบบ | ★★ |
| ลำดับ Inspection ก่อน Palpation ในระบบสืบพันธุ์/ทวารหนัก | นักศึกษามักข้ามการดูก่อนคลำ | เหมือนหลักทั่วไปของ PE (Inspect ก่อน Palpate เสมอ) | ทั้งหญิง ชาย และ Anal area ต้อง Inspection ก่อนแล้วจึง Palpation | ★★ |
